# Cuboid

Thriller de acción multijugador en primera persona para navegador. Cada jugador despierta **aislado en un cuarto sellado** dentro de una megaestructura cúbica y debe correr, resolver y decidir rápido para seguir respirando. Cada partida es cerrada, y solo algunos alcanzan la Salida.

Inspirado en la ciencia ficción y en los "juegos mortales" del estilo de *Alice in Borderland*.

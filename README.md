# Cuboid

Juego multijugador online de supervivencia y pruebas. Cada jugador despierta **aislado en un cuarto sellado** dentro de una megaestructura cúbica y debe superar pruebas de lógica, habilidad y confianza para seguir respirando.

Inspirado en la ciencia ficción y en los "juegos mortales" del estilo de *Alice in Borderland*.
